## 소개

외부 연동과 업무 자동화를 중심으로 경력을 쌓은 백엔드 개발자입니다.

첫 직장에서 100여 개 쇼핑몰의 데이터 수집 시스템을 운영했고, 2020년부터 도매사 56곳과 주요 오픈마켓을 잇는 수집, 등록, 주문, 발주, 송장 자동화 서비스를 직접 설계, 개발, 운영했습니다. 2024년 아이오스㈜로 법인화하여 고객사 10곳, 월 거래액 약 1억 원, 등록 상품 약 30만 개 규모로 운영했습니다. 이후 자동차 제조업 ICT팀에서 VB 기반 ERP를 React 웹앱으로 확장하고, Python RPA로 데이터 수집을 자동화하여 연간 약 1,000시간의 수작업을 줄였습니다.

## 주요 프로젝트

### 1. AIOS 전자상거래 통합 자동화 서비스

- 기간: 2020.03 ~ 2025.12
- 인원: 1명 (기획, 설계, 개발, 인프라, 운영)
- 기술: Node.js, Express, MySQL, MongoDB, Selenium, Puppeteer, React, AWS
- 상세: [projects/aios.md](./projects/aios.md)

도매사 상품을 수집해 오픈마켓에 등록하고, 들어온 주문을 도매사에 자동 발주하여 송장까지 등록하는 셀러용 자동화 서비스입니다.

- 도매사 56곳을 cafe24, 고도몰, 메이크샵 등 11개 플랫폼 계열의 공통 모듈 규격으로 연동하여, 신규 도매사는 같은 계열 모듈을 복제해 추가할 수 있도록 구성
- API 서버는 요청 검증 후 즉시 응답하고 실제 작업은 자식 프로세스로 분리하여, 한 고객의 작업이 다른 고객의 작업을 막지 않도록 설계
- 작업별 잠금, 1,000건 단위 재개, 로그인 세션 캐시로 중복 실행과 도매사 IP 차단 문제 해결
- 고객별 DB 분리와 JWT 권한 구조로 멀티테넌트 환경 운영
- 하루 평균 150건의 주문을 발주부터 송장 등록까지 무인 처리 (수작업 기준 하루 7시간 이상)
- 고객사 10곳, 월 거래액 약 1억 원, 등록 상품 약 30만 개 규모로 운영

### 2. 제조 현장 업무 전산화 (㈜금창4공장)

- 기간: 2025.05 ~ 2026.07
- 기술: Node.js, Express, Python, React, MSSQL, VB ERP, Selenium
- 상세: [projects/geumchang.md](./projects/geumchang.md)

자동차 제조업 현장의 VB 기반 ERP를 웹으로 보완하고, 반복 입력 업무를 자동화했습니다.

- VB 기반 ERP를 보완하는 사내 웹포탈(React, Node.js) 구축, 근태관리와 공정순회일지를 데스크탑·태블릿용 웹앱으로 전환
- MES 데이터 기반 대시보드(라인별 불량률, 태양광 발전량, 온습도)와 QR 스캔 자재 입출고 기능 구현
- Python RPA로 모기업 협력사 포털의 대외문, 수주, 클레임 데이터를 자동 수집하여 ERP에 등록. 연간 약 1,000시간 절감, 수집 주기를 주 2회에서 매시간으로 단축
